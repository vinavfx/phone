# Phone

Herramientas para el teléfono Android.

- [`prefix-blocker/`](prefix-blocker/README.md): bloquea llamadas entrantes por prefijo.
- [`sms/`](sms/README.md): muestra en Linux los SMS del teléfono a través de la red local.
- [`cli/`](cli/README.md): comando `ph`, por ejemplo `ph code` para el último código de verificación.

Las herramientas de compilación compartidas (JDK, SDK de Android y Gradle) se guardan en `.tools/`, excluido de Git.
